## Stable contracts for HAC-71/HAC-72

`api.families.listMine({})` returns `{familyId,name,slug,role,helperAddress}[]` for the current stable user ID. `create({name})` atomically creates the family and admin membership; retrying the same name returns it. One created family per user is the current explicit product limit, with up to 50 total joined families. Existing `cases.listBoard({familySlug})`, note and handled contracts remain intact. Slugs only navigate; membership remains mandatory. The `?demo=1` frontend fixture remains isolated.

`families.setup({familyId})` is admin-only and returns family, helperAddress, parents and sanitized pending-link metadata. `saveParent({familyId,parentId?,requestId,name,knownInstitutions})` creates/updates parent details. Reuse a stable requestId across retries. `parents.emails` contains only confirmed addresses; active `parentEmails` rows are inserted in the same confirmation transaction. The internal demo seed now refuses cross-family route conflicts before any write. Existing internally seeded routes remain operator-authorized; this change does not silently reclassify or backfill them.

`requestParentEmail({parentId,email})` and `invite({familyId,email})` return status plus deliveryStatus (`sent`, `captured`, `failed`, or `unchanged`), never a token. `sent` means provider acceptance, not confirmed receipt. `previewLink({token,kind})`, `confirmParentEmail({token})` and `acceptInvitation({token})` accept the private email token. Parent confirmation is explicit consent with no account; invitation acceptance requires matching normalized, verified database email and grants only member. `revokeLink({linkId})` is admin-only. A consumed/revoked/expired link cannot grant access; stale delivery completion cannot overwrite a newly issued token.

Tokens contain 256 random bits and only SHA-256 hashes are persisted in setupLinks. Links expire after 24 hours. Tokens arrive in URL fragments (`?confirmParent=1#token=…` / `?acceptInvite=1#token=…`), are never in family queries, and require explicit acceptance. Token changes within one tab clear the old preview and guard stale asynchronous results. Limits: 20 parents/family, 10 confirmed addresses/parent, 10 known institutions/parent, 250 setup-link slots/family, 50 members/family and 10 setup emails/admin/hour. Account email issuance shares a normalized-address bound (5/hour) and global bound (100/hour); verified password sign-in does not consume email quota.

Family institutions stay exclusively in `parents.knownInstitutions` as unverified context; neither arbitrary websites nor domains enter `officialOrgs`. HAC-71 can use listMine and existing board contracts; HAC-72 must resolve current membership and confirmed parent addresses rather than treating pending requests or entered institution domains as trusted.
